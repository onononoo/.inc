# Settings reference

Generated by `npm run docs` from the settings schema. Do not edit by hand.

Settings are layered. From lowest to highest priority: built-in defaults, your user `settings.json`, the workspace file `<folder>/.inc/settings.json`, and the enterprise policy file (see [ADMIN.md](ADMIN.md)). A setting marked *workspace* may be overridden per folder. A setting marked *restricted* is ignored from a workspace until the folder is trusted.

## Files

| Setting | Type | Default | Description |
| --- | --- | --- | --- |
| `files.autoSave` | enum | `"off"` | Save modified files automatically. One of: `off`, `afterDelay`, `onFocusChange`, `onWindowChange`. |
| `files.autoSaveDelay` | number (100–60000) | `1000` | Delay before saving when auto save is set to "After a delay". |
| `files.eol` | enum | `"auto"` | Line ending for new files. Existing files keep their own line endings. One of: `auto`, `lf`, `crlf`. *(workspace)* |
| `files.encoding` | enum | `"utf8"` | Encoding for new files. Existing files keep the encoding they were read with. One of: `utf8`, `utf8bom`, `utf16le`, `utf16be`, `windows1252`, `iso88591`, `windows1251`, `koi8r`, `shiftjis`, `eucjp`, `gbk`, `big5`, `euckr`. *(workspace)* |
| `files.trimTrailingWhitespace` | boolean | `false` | Remove trailing whitespace when saving. *(workspace)* |
| `files.insertFinalNewline` | boolean | `false` | End files with a newline when saving. *(workspace)* |
| `files.useEditorConfig` | boolean | `true` | Apply indentation, line endings, encoding and whitespace rules from .editorconfig files. EditorConfig takes precedence over the settings above. *(workspace)* |
| `files.exclude` | record<boolean> | `{"**/.git":true,"**/.hg":true,"**/.svn":true,"**/.DS_Store":true,"**/Thumbs.db":true}` | Glob patterns for files and folders to hide in the explorer and quick open. *(workspace)* |
| `files.watcherExclude` | record<boolean> | `{"**/.git/objects/**":true,"**/.git/subtree-cache/**":true,"**/node_modules/**":true,"**/.hg/store/**":true}` | Glob patterns to leave out of file watching. Excluding large folders keeps startup and memory low in very large repositories. *(workspace)* |
| `files.confirmDelete` | boolean | `true` | Ask for confirmation before moving files to the trash. |
