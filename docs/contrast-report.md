# Contrast report

Generated by a node script from `src/renderer/styles/tokens.css` using the WCAG 2.x relative luminance formula. Translucent fills are composited over the named base surface(s) before measuring.

Targets: default themes 4.5:1 for text, status, syntax and git colours; 3:1 for component boundaries, icons, focus rings and graphics. High-contrast themes 7:1 for text on surfaces (4.5:1 floor for text drawn inside translucent selection, find and bracket overlays).

Checks run: 826. Passing: 824. Failing: 0. Documented exemptions: 2.

## Residual failures

No unresolved failures.

Documented exemptions (not counted as failures):

- dark: `ansi-black` on `terminal-bg` = 1.58:1 (needs 4.5:1). ansi-black used as TEXT on terminal-bg (exempt: fill/label colour only)
- hc-dark: `ansi-black` on `terminal-bg` = 1.62:1 (needs 7:1). ansi-black used as TEXT on terminal-bg (exempt: fill/label colour only)

`ansi-black` is the terminal's black. Programs that print black text on a dark terminal background produce low contrast by definition, so the value is only guaranteed as a fill or as a label on coloured chips. In the dark themes it deliberately stays close to the surface so that black-background regions (progress bars, reverse video) are visible against the terminal.
